Overview

What it does

Modern SDA is a full replacement for the original Steam Desktop Authenticator. It manages multiple Steam accounts simultaneously, generates live Guard codes with a countdown timer, and handles every type of Steam confirmation — trades, market listings, API key activations — without needing the mobile app.

Built with PyQt5 for a native desktop feel, it stores refresh tokens so you never re-login on every launch. A per-account HTTP proxy system lets you isolate traffic per account when needed.

Installation

Getting started

Requires Python 3.10+. Install dependencies and run:

bash
# Install dependencies
pip install PyQt5 aiosteampy aiohttp

# Run the application
python main.py

To add an account, click the + button, select your .mafile (from SDA or compatible tools), enter your password, and optionally a proxy URL.
