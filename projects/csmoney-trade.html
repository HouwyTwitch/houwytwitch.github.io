CS.Money
Auto Trade

Replicates the logic of the official CS.Money Chrome extension in pure Python. Automatically processes sale offers, creates Steam trade offers, and confirms them via Steam Guard — no manual action required.

Overview

What it does

When a buyer purchases your CS.Money listing, this tool handles everything automatically. It reverse-engineers the CS.Money Chrome extension flow — including the RSA-6144 session encryption scheme used to securely hand off Steam credentials to CS.Money's servers.

Sessions and cookies are persisted to disk so restarts don't require a new login. Rate-limit responses (error code 9999) are handled gracefully — the current cycle is skipped and retried on the next poll.

How It Works

Automated offer flow

01
Notification polling
Polls GET /1.0/market/notifications every poll_interval seconds. On an OFFER_BOUGHT event, immediately checks for pending trades.
02
Fetch active offers
Polls GET /3.0/market/active-offers every 30s as a fallback safety net.
03
Notify CS.Money & send trade
For each CREATING-state offer: notifies CS.Money via POST, then sends the Steam trade offer directly to the buyer.
04
Encrypt & report session
Fetches RSA-6144 public key, encrypts Steam session credentials, reports trade offer ID and session back to CS.Money.
05
Steam Guard confirmation
Confirms the trade offer via mobile authenticator using identity_secret.
