Buff.market
Auto Trades

Automatically delivers sold CS2 items on Buff.market. Handles Steam OpenID login, RSA-4096 encrypted session handoff, and Steam Guard confirmation - entirely hands-free.

View on GitHub ↗
Overview

What it does

When you sell an item on Buff.market, the funds are held until you manually deliver it. This bot eliminates that step entirely. It logs in via Steam OpenID - no API key or manual cookie required.

The most technically interesting part: it replicates the hybrid RSA + AES-128-CBC encryption scheme reverse-engineered from the Buff Android APK.

How it works

Delivery flow per order

01
Login
Authenticates with Steam via aiosteampy, then runs the Steam OpenID flow against Buff's API.
02
Poll orders
Fast poll every 15s. Full order list fetched from /api/market/sell_order/to_deliver.
03
Encrypt session
Serializes Steam session cookies as JSON and encrypts with Buff's RSA-4096 public key using hybrid RSA + AES-128-CBC.
04
Send to Buff
POSTs encrypted session to seller_send_offer. Buff decrypts and sends the trade to the buyer.
05
Steam Guard confirm
Confirms the trade offer using identity_secret from your .maFile.
