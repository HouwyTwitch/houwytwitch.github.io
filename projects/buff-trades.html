Buff.market
Auto Trades

Automatically delivers sold CS2 items on Buff.market. Handles Steam OpenID login, RSA-4096 encrypted session handoff, and Steam Guard confirmation — entirely hands-free.

Python asyncio Buff.market API RSA-4096 AES-128-CBC Steam OpenID aiosteampy
View on GitHub ↗
Overview

What it does

When you sell an item on Buff.market, the funds are held until you manually deliver it. This bot eliminates that step entirely. It logs in via Steam OpenID — no API key or manual cookie required — then polls for TO_DELIVER orders every 15 seconds.

The most technically interesting part: it replicates the hybrid RSA + AES-128-CBC encryption scheme reverse-engineered from the Buff Android APK to securely hand off Steam session cookies so Buff's servers can send the trade offer on your behalf.

How It Works

Delivery flow per order

01
Login
Authenticates with Steam via aiosteampy, then runs the Steam OpenID flow against Buff's API automatically.
02
Poll for pending orders
Fast poll of /api/message/notification every 15s. Full order list fetched from /api/market/sell_order/to_deliver.
03
Encrypt session
Collects Steam session cookies, serializes as JSON, encrypts with Buff.market's RSA-4096 public key using hybrid RSA + AES-128-CBC — replicated from the Android APK.
04
Send to Buff
POSTs encrypted session to /api/market/manual_plus/seller_send_offer. Buff decrypts and sends the trade offer to the buyer.
05
Confirm via Steam Guard
Confirms the trade offer using identity_secret from your .maFile.
Installation

Setup

bash
pip install -r requirements.txt
cp config.example.json config.json
# Fill in your credentials
python main.py

Optional flags:

bash
python main.py --config PATH
python main.py --log-level DEBUG
python main.py --trace-http  # full HTTP req/resp logging
