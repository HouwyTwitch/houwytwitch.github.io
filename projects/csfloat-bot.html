CSFloat
Auto Bot

Async Python bot that fully automates the CS2 seller flow on CSFloat. From sale detection to Steam Guard confirmation — no browser extension, no manual action required.

Python 3.11+ asyncio aiohttp CSFloat API Steam API aiosteampy systemd
View on GitHub ↗
Overview

What it does

CSFloat has no public WebSocket or SSE stream. This bot uses a dual-tier polling system — fast notification polling every 15s and a 60s heartbeat fallback — to react to new sales as quickly as practically possible, then automates the full trade lifecycle without any browser extension.

Steam session cookies are persisted to disk so the bot avoids a full re-login on subsequent runs. All configuration lives in a single JSON file.

How It Works

Full trade lifecycle

01
Detect new sales
Fast notification polling via /api/v1/me/notifications every 15s. Heartbeat fallback every 60s catches anything missed.
02
Bulk-accept trades on CSFloat
Calls the CSFloat REST API to accept pending trade offers programmatically.
03
Send Steam trade offer
Directly sends the trade offer to the buyer via Steam's trade API — no browser needed.
04
Confirm via Steam Guard
Uses identity_secret from your .maFile to confirm the offer with mobile authenticator logic.
05
Notify CSFloat
Calls the steam-status API to mirror what the CSFloat Chrome Extension does — keeps trade state in sync.
Installation

Setup

bash
git clone https://github.com/HouwyTwitch/csfloat-auto-sale-and-trade
cd csfloat-auto-sale-and-trade
pip install -r requirements.txt
cp config.example.json config.json
# Edit config.json with your credentials
python main.py

Optional flags:

bash
python main.py --config /path/to/my.json
python main.py --log-file bot.log
python main.py --log-level DEBUG
python main.py --trace-http  # log every HTTP req/resp
Configuration

config.json keys

KeyRequiredDescription
csfloat_api_keyYesCSFloat API key (Profile → Developer)
steam_id64YesYour 17-digit SteamID64
steam_loginYesSteam username
steam_passwordYesSteam password
shared_secretYesFrom .maFile — 2FA login codes
identity_secretYesFrom .maFile — trade confirmation
client_proxyNoSOCKS5 proxy for CSFloat traffic
notif_interval_secondsNoNotification poll interval (default: 15)
Production

Running as a systemd service

/etc/systemd/system/csfloat-bot.service
[Unit]
Description=CSFloat Auto-Sale Bot
After=network-online.target

[Service]
Type=simple
User=youruser
WorkingDirectory=/home/youruser/csfloat-auto-sale-and-trade
ExecStart=/usr/bin/python3 main.py --log-file /var/log/csfloat-bot/bot.log
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
