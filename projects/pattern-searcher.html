Overview

What it does

In CS:GO, certain skins have a pattern index (seed) that determines their visual appearance. Some patterns are extremely rare - specific Case Hardened blue gem configurations, maximum Fade percentages. These skins sell for multiples of the base price.

This bot continuously monitors the market for these specific patterns and purchases them the moment they're listed below a configured threshold.

How it works

Detection & purchase flow

01
Define targets
Configure specific pattern indices and maximum purchase prices per skin type.
02
Continuous scan
Polls the CS:GO market API in real time, checking new listings against the target list.
03
Pattern analysis
Fetches inspect link data to verify the actual pattern index before purchasing.
04
Auto-buy
Executes the purchase automatically when a target pattern appears at or below threshold.
