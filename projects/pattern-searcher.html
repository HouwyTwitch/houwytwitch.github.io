Overview

What it does

In CS:GO, certain skins have a pattern index (seed) that determines their visual appearance. Some patterns are extremely rare — specific Case Hardened blue gem configurations, maximum Fade percentages, or low-numbered Marble Fades. These skins sell for multiples of the item's base price.

This bot continuously monitors the market for these specific patterns and purchases them the moment they're listed at a price below a configured threshold — before any human buyer could react.

How It Works

Detection & purchase flow

01
Define targets
Configure specific pattern indices and maximum purchase prices for each skin type you want to hunt.
02
Continuous market scan
Polls the CS:GO market API in real time, checking new listings against the target pattern list.
03
Pattern analysis
Fetches inspect link data for each matching listing to verify the actual pattern index before purchasing.
04
Auto-buy
Executes the purchase automatically when a target pattern appears at or below the configured price threshold.
