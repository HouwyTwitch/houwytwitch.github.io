Overview

What it does

Modern SDA Android is the mobile companion to the desktop authenticator. It uses the standard .mafile format so any account already set up in the original SDA works instantly. All traffic goes directly to Steam's official APIs — no third-party servers, no telemetry.

Built with Jetpack Compose and Material 3, it supports dynamic color theming. Device backups are disabled to prevent credentials appearing in cloud backups, and release builds strip all debug logging.

Features

Key capabilities

01
Multi-account support
Import any number of .mafile accounts. Switch between them instantly.
02
TOTP with animated countdown
30-second Steam Guard codes with a visual countdown ring — always visible.
03
Trade & market confirmations
View, accept, or decline confirmations with swipe-to-refresh. Auto-refresh in the background.
04
Auto session refresh
Silently re-authenticates using stored refresh tokens — no repeated password prompts.
05
Material 3 UI
Dynamic color, dark/light theme, per-device theming. Targets Android 11+ (API 31).
Installation

Building from source

Requires Android Studio Ladybug (2024.2+) and JDK 17. The app targets API 35 and runs on API 31+.

bash
# Clone and open in Android Studio
git clone https://github.com/HouwyTwitch/Modern-SDA-Android.git

# Build a debug APK
./gradlew assembleDebug

# Output
app/build/outputs/apk/debug/app-debug.apk

To import an account: tap +, paste your .mafile JSON content, optionally enter your Steam password for auto re-login, then tap Import.
