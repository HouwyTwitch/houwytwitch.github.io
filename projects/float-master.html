Overview

What it does

In CS:GO, a trade-up contract takes 10 skins and produces one skin from the next rarity tier. The output skin's float value is the weighted average of the 10 input floats, mapped through a formula specific to each skin's min/max float range.

Finding the exact combination of 10 input skins that produces a desired output float is a combinatorial search problem. With thousands of possible input floats, the search space is enormous — impractical for a CPU. This tool offloads the entire computation to the GPU using CUDA, searching millions of combinations per second.

The Problem

Why GPU?

Suppose you want a Factory New AWP | Dragon Lore at a float below 0.01 (extremely rare, worth a significant premium). To find inputs that produce this output, you need to evaluate:

math
C(n, 10) combinations where n = number of available inputs

# Example: 500 available skins → ~2.6 trillion combinations
# CPU: ~years at single-thread speed
# GPU (CUDA): seconds to minutes

The CUDA kernel evaluates each candidate combination in parallel across thousands of GPU cores, making the previously impossible practical.

How It Works

Computation pipeline

01
Define target
Specify the desired output skin and target float range. Provide the pool of available input skins with their floats.
02
Upload to GPU
Input float values are transferred to GPU memory. CUDA kernel is compiled and launched across all available CUDA cores.
03
Parallel brute-force
Each GPU thread evaluates a subset of combinations, computing the weighted average float and checking if it falls within the target range.
04
Return results
Matching combinations are collected from GPU memory and returned — ready to execute as actual trade-up contracts.
